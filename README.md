# Certificate Images

Put your scanned certificate images in this folder.

## Required filenames (must match exactly):

| File name                  | Certificate                                  |
|---------------------------|----------------------------------------------|
| nptel-networks.jpg        | NPTEL Computer Networks (IIT Kharagpur)      |
| ibm-webdev.jpg            | IBM Web Development Fundamentals             |
| ibm-ai.jpg                | IBM AI Fundamentals                          |
| genai-bootcamp.jpg        | Generative AI Bootcamp (BV College)          |
| udemy-python.jpg          | Python Course (Udemy)                        |
| hawkathon-2026.jpg        | UAi Hawkathon 2026 Certificate               |
| fossee-python.jpg         | FOSSEE Python Workshop (IIT Bombay)          |

## Tips:
- JPG or PNG both work fine
- Scan at 150+ DPI for crisp quality
- If you only have a screenshot, that's fine too
- Crop out any white margins if possible
- Max recommended size: 1MB per image (compress at tinypng.com if needed)

Once you add any image here, it will automatically show up in the Certificate Gallery
on your portfolio with a zoom/lightbox view.
